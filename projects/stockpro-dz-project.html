Key Features

Live Dashboard
Real-time KPIs: total products, low stock alerts, out-of-stock count and total inventory value in DZD.
Movement Chart
Pure CSS bar chart showing incoming vs outgoing stock over 6 months — no chart library needed.
Add / Delete Products
Modal form to add products with name, category, quantity and price. One-click delete with instant update.
CSV Export
Export full product list or filtered reports as a .csv file with Arabic headers — Excel-ready.
Search & Filter
Real-time search by name or category. Filter reports by status or category breakdown.
RTL Arabic UI
100% right-to-left layout with Cairo font — built natively for Arabic-speaking Algerian users.
