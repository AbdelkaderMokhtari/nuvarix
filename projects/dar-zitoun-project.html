Key Features

Scroll Animations
Every section reveals with elegant fade-up transitions triggered on scroll using IntersectionObserver.
Interactive Menu
Tabbed menu with category filtering and bilingual dish names.
Reservation Form
Full reservation system with date validation, guest count, time slots and toast confirmation.
Masonry Gallery
CSS multi-column masonry layout with hover label reveals and a gold overlay effect.
Bilingual Content
Arabic and English throughout — with RTL support baked in.
Fully Responsive
Mobile-first layout collapses, hamburger navigation, fluid typography on all screens.
